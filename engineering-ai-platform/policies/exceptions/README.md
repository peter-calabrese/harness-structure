# Policy Exceptions

Temporary exceptions to `policies/` rules must be documented in this directory as `<YYYY-MM-DD>-<short-name>.md`.

## Required Fields

- **Policy Rule**: Which policy and rule ID is exempted.
- **Repository / Scope**: Exact repository and file paths covered.
- **Justification**: Why compliance is currently blocked.
- **Mitigation**: Compensating controls in place.
- **Expiration Date**: Maximum 90 days from approval.
- **Approver**: `@platform-security` or `@platform-ai` owner handle.
