# Design System Standards

- Always compose from existing design-system primitives (`Button`, `Input`, `Dialog`, `Stack`) before building custom UI controls.
- Expose a consistent `variant`, `size`, and `disabled` API on shared components.
- Support controlled and uncontrolled usage where appropriate.
- Document every shared component with usage examples and accessibility notes.
