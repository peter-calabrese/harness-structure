# Styling Standards

- Use design tokens (CSS custom properties or theme tokens) for colors, spacing, typography, and radii; avoid hardcoded hex values.
- Prefer utility classes or scoped CSS modules over global stylesheets.
- Design mobile-first responsive layouts using CSS Grid and Flexbox.
- Respect `prefers-reduced-motion` for all animations and transitions.
