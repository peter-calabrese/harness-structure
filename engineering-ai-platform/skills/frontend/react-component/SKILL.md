# React Component Skill

## When to Use

When creating a new UI component or refactoring an existing one.

## References & Assets

- Patterns: `references/component-patterns.md`
- Starter template: `assets/component-template.tsx`
- Validator script: `scripts/validate-component.sh`

## Workflow Steps

1. Review `references/component-patterns.md` and `standards/frontend/react.md`.
2. Start from `assets/component-template.tsx` and define explicit TypeScript props.
3. Ensure keyboard navigation, semantic HTML, and design tokens are used.
4. Run `scripts/validate-component.sh <component-file>` to verify conventions.
